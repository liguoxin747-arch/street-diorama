# 《过街》· 游戏策划案 v0.1

> 一个街区，一夜，三到四个人。
> 本文按**现有 diorama 的实际坐标与资产**编写，括号里标的是可直接复用的东西。
> 地图迭代时对着本文改：§7 是"地图需要你补什么"的清单。

---

## 1. 一句话

天黑到天亮之间，带着三四个平民从这个被两军夹住的街区穿过去。

**类型**：回合制潜行战术（每回合 = 3 秒实时）
**时长**：单局 40~60 分钟，可重复挑战
**镜头**：沿用现在的微缩环绕视角（移轴 + 冷夜雨），不改成越肩

---

## 2. 为什么是回合制（设计依据，不是口味）

| 现有资产 / 约束 | 对应的设计决定 |
|---|---|
| 阴影一次性烘焙、30 盏点光，逐片元很贵 | 一次只动一个单位 → 性能压力消失 |
| 没有导航网格，只有道路走廊 + 可行走格 | 不做自由寻路，做**路径点 + 可见性判定** |
| 没有室内（仅别墅、商铺、防空洞可进） | 玩法靠**绕路与时机**，不靠房间探索 |
| 地图 288 m，横穿 40 秒 | 不做战役，做**一关**，把密度做满 |
| 微缩俯视 + 移轴 | 玩家是"看棋盘的人" → 天然契合战术视角 |
| 现有平民点：老妇推车、两个孩子、做饭的主妇 | 主角设定为**平民**，而不是士兵 |

---

## 3. 核心循环

```
观察（暂停）→ 下指令（移动/蹲伏/屏息/互动）→ 时间推进 3 秒 → 世界响应 → 观察
```

- **移动**：走 / 蹲（更慢、更难被看到、踩声更小）/ 冲刺（快、很响）
- **暴露度**：由「所处光照 × 距离 × 是否蹲伏 × 遮挡」决定，不是布尔值
- **怀疑度**：敌人有 0~100 的怀疑条。进入视野涨、离开缓慢降；满了才开火。**不秒杀**
- **声源**：踩碎瓦、开门、跑动、开枪都会产生一个带半径的声音事件

---

## 4. 三个支点（全部用现成资产）

### 4.1 光 = 暴露（不需要 UI）

- 场上有 **76 盏路灯**，其中约 20% 是倾倒/倒地的（`streetlights.ts`），还有几盏会闪
- 3 盏带真实阴影的灯池会跟着镜头重新分配（`lamp-pool-shadow-*`）→ 光斑是**活的**，可以当动态危险区
- 另有燃烧的油桶（`27.4, 52.3`）、弹坑灯、照明弹
- **规则**：站进光斑 = 远处也能被看到；站在阴影里 = 只有很近才会被发现
- **玩家动作**：打碎灯泡 / 拉电闸 / 用照明弹反制（照亮的瞬间敌人也会失去夜视优势）

> 这样"亮/暗"本身就是 UI。玩家学会读环境，就不用叠线框。

### 4.2 雨 = 掩护

现有雨幕已经是全场特效。把它做成**玩法变量**：

- 雨大 → 声音传播半径缩小，可以小跑
- 雨小/停 → 脚步声传得远，必须爬
- 建议按"每 4~6 回合一阵"的节奏切换，给玩家可预期的窗口

### 4.3 车队 = 时间压力 + 掩体

车队会从地图边缘进出（`vehicles.ts` 里的 convoy）：

- 车灯扫过路面 → 临时把一段暗路变成亮路
- 引擎声 → 掩盖你的脚步（跟随车队通过 = 免费掩护）
- 车队离开地图 = 一次"关卡节拍器"，也是撤离窗口

## 5. 关卡结构：一条街的五幕

主角从**东侧工业区边缘**出发，目标是**西侧平民区**（或南门），全程不出这张图。

| 幕 | 位置（现有坐标） | 玩法 | 现成资产 |
|---|---|---|---|
| 一·出发 | 东郊 `x≈110~130` | 教学：学会蹲、学会看光 | 工业区筒仓、哨卡外沿、拒马 |
| 二·封锁 | 大道 `z≈0`，`x≈50~70` | 军事哨卡 + 路面断裂 `(55, 2.2)` | 防空洞 `(50.5,-10.6)`、BTR、沙袋、铁丝网、探照塔 |
| 三·斜穿 | 路口 `(0,0)` | 核心抉择：走大道（快/暴露）还是巷子（慢/安全） | 主楼街角 `x[12,34] z[-34,-13]`、BMPT `(-4.2,-23.5)`、T-72 残骸、斑马线 |
| 四·地下 | 地陷 `(-44, 1.2)` r6.8 | 垂直空间：下坑、穿过断楼楼板 | 地陷、两栋剖切楼 `(34,43.5)` `(76,-25)`、废墟堆 |
| 五·撤离 | 西侧 `x≈-110` 或南门 `z≈132` | 天亮倒计时下的最后一段 | 平民区窄巷、院子、别墅 `(22,21)` |

**三条路线**（互相排斥的取舍，而不是"最好的那条"）：

1. **大道**：最短，全程暴露在路灯与哨卡视线下，但能借车队掩护
2. **巷子/后院**：三处设计好的巷道（`ALLEYS`）+ 院子；安全但绕远，且要翻塌墙
3. **地陷/断楼**：唯一能绕过哨卡的路线；需要绳索/梯子，动作慢、会响

## 6. 队伍与目标

**三名平民**（可变）：

| 角色 | 能力 | 代价 |
|---|---|---|
| 母亲 | 能安抚/带走 NPC（孩子、老妇） | 移动慢，带人时更慢 |
| 老人 | 懂路：能提前显示一段路的巡逻习惯 | 体力差，冲刺有冷却 |
| 青年 | 能攀爬、能破坏（砸灯、撬门） | 动作声音最大 |

**胜利**：至少 1 人抵达撤离点 → 结局按活着的人数分级
**失败**：全灭，或**天亮**（用现有昼夜装置推进天空，黎明即失败）

> 昼夜系统已经有 `dayLength` 和 `setTime`，天亮不用新写天空——把它从"氛围"改成"计时器"就行。

## 7. 地图需要你补什么（你后续迭代的优先级）

按对玩法的影响排序：

1. **更多可进的门洞**（每 2~3 个街区至少 1 个）——潜行游戏最缺的是"藏"
2. **可爬的垂直路径**：断楼楼板、车库顶、废墟堆斜面——提升路线多样性
3. **可交互的灯**：灯泡可打碎、电闸可拉（哪怕只是 `mesh.visible`）
4. **可藏容器**：木箱、柜子、车底、柴堆——现成的箱子加个交互即可
5. **保证"亮/暗"两态**：现在部分区域是均匀灰，需要更明确的光池与深影
6. **2~3 条清晰的穿越走廊**：避免"全是墙"（走不通）或"全开敞"（没得选）

## 8. 技术里程碑

| 阶段 | 内容 | 验收标准 |
|---|---|---|
| **M0 读地** | 自由行走 + 危险区可视化（临时调试用） | 能主观判断"这里会被看到吗"，且判断和系统一致 |
| **M1 一次穿越** | 1 个角色、2 条巡逻、1 盏灯、1 个终点 | 能玩通；被发现的反馈合理 |
| **M2 回合制** | 3 秒回合、指令队列、3 人小队、声/光 | 暂停→下令→推进的手感成立 |
| **M3 关卡事件** | 哨卡、照明弹、车队掩护、天亮倒计时 | 五幕能连成一条 45 分钟的体验 |
| **M4 演出** | 动画、音效、结局、存档 | 可交付 |

**M0 的判断标准**（最重要的一条）：不看任何 UI，玩家能不能从画面里读出"这条线危险、那条线安全"。读不出来，后面全白做。

---

## 9. 明确不做

- 开放世界、大兵团 RTS（地图只有 288 m，没有纵深）
- 第一人称射击（缺室内、缺动画、缺枪械手感）
- 室内恐怖/沉浸模拟（几何没有室内）
- 多人联机

---

## 10. 风险

| 风险 | 说明 | 对策 |
|---|---|---|
| **可读性** | 微缩俯视 + 密集细节，容易看不清掩体与视线 | 用光当 UI（§4.1），并用 M0 验证 |
| 单位数量 | 移动单位会打破静态阴影的假设 | 回合制本身限制了同时移动量；必要时只给玩家单位投动态影 |
| 一个街区的重复度 | 玩第三遍就腻 | 三路线 + 随机雨/车队时机 + 角色能力差异 |
| 内容量 | 一关 45 分钟，很容易做不够 | 把密度压在"抉择"上（每 3 分钟一个两难），而不是延长路线 |
