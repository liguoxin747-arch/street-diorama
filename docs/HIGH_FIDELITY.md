# 高保真建模规范（High-Fidelity Modeling）

本项目所有资产统一的"细节语言"。目标是**精致的 3D 拼装模型（田宫/万代高达模型或高品质动画电影场景）**，
而不是照片级写实。

## 三条铁律

1. **几何优先**：结构感来自**真实建模出来的体块、凹凸、厚度**，
   而不是贴图细节。剥落的墙皮必须是**有厚度、边缘参差**的片；
   门窗必须是**有洞口侧壁和窗台进深**的构造，不能是贴上去的平面。
2. **轮廓线优先**：`withOutline()` 只加在**剪影重要的体块**上
   （建筑主体、车辆壳体、人物、单个道具）。碎屑、砖块、瓦砾用**明暗分层**表达，
   不给它们描边（否则画面变脏、draw call 爆炸）。
3. **色彩克制**：色板只有冷灰蓝（夜）+ 暖橙（火光/灯火）两族。
   战损用**去饱和的锈褐/焦黑**，不用鲜红、亮黄、纯白高光。

## 尺寸锚点（真实尺度，1 单位 = 1 米）

| 物件 | 尺寸 |
|---|---|
| 砖 | 0.25 × 0.065 × 0.12 |
| 瓦（叠放顺序可见） | 0.28 × 0.02，长边搭接 0.12 |
| 窗洞 | 宽 1.1–1.4，高 1.4–1.6，洞口侧壁进深 = 墙厚 0.55 |
| 弹孔 | 直径 0.04–0.08，崩裂碎屑环 0.12–0.2 |
| 沙袋 | 0.55 × 0.22 × 0.32（压扁、错缝、褶皱） |
| 履带节 | 长 0.38 × 宽 0.6 × 厚 0.08，带驱动齿 |
| 胎纹块 | 0.18 × 0.06 × 0.04，人字形排布 |
| 人 | 1.72；头盔半径 0.13；防弹背心厚 0.12 |
| 军车 | BMPT 6.4×2.4×7.2；T-72 车体 3.6×2.3×6.9 + 炮管 6.1 |

## 明度分层规则（三渲二的关键）

同一块墙面上，**至少 3 个可区分的明度层级**：
基色 → 剥落面（暗/砖色）→ 积灰/熏黑（更暗）→ 边缘高光（亮，1px 级）。
相邻构件之间要有**明确的明度差**，不要同色相接。

## 性能红线

- 单个模块：mesh 增量 ≤ +200，三角面增量 ≤ +120k
- 碎件（砖、瓦砾、弹壳、书纸、履带板、胎纹）**一律 instanced**
- 静态碎件**按材质合并**（复用 `mergeMeshes` / `addBatch`）
- 描边只给体块；每加一个描边 hull = +1 draw call × 阴影 pass

## 反面清单（不要出现）

- 平贴的墙面（没有洞口进深的门窗）
- 纯色大方块当"家具"
- 均匀撒在整面墙的等距弹孔
- 高饱和纯色油漆（除非是暖光源附近）
- 给每个小碎件都描边
- 用贴图模拟厚度
